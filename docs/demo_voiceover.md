# Demo Voiceover Script (2:30)

Use this script while showing the running app UI.

## 0:00–0:15 — Problem framing

“Tax prep still assumes humans should do repetitive cognitive work: reading slips, retyping numbers, and reconciling totals manually. I rebuilt that workflow as an AI-native system called WealthTax Agent.”

## 0:15–0:35 — What the system is

“This prototype takes synthetic Canadian slips like T4, T5, and RRSP receipts, parses them, builds a draft tax summary, explains key numbers in plain English, and then hands the final approval decision to a human.”

## 0:35–0:55 — Upload + trigger

“I’m uploading a few synthetic slips now. Then I click Generate draft return. The AI now owns document parsing and initial synthesis, instead of the human manually entering fields one by one.”

## 0:55–1:25 — Show output metrics

“Here’s the draft summary: total income, RRSP deduction, taxable income, and estimated tax. This is the high-leverage shift — the user moves from data-entry operator to quality reviewer.”

## 1:25–1:50 — Explainability + reliability

“Below that, each key number is explained in plain language so the user can validate reasoning quickly. If parsing or explanation fails, the app surfaces warnings and uses deterministic fallback behavior, so the workflow degrades gracefully instead of crashing.”

## 1:50–2:15 — Human boundary (critical)

“This is the critical boundary: AI can draft and explain, but it cannot make the legally material decision. The human must explicitly approve whether this draft should be used. Filing responsibility remains fully human.”

## 2:15–2:30 — Scale realism

“What breaks first at scale is long-tail document variability and tax-policy edge cases, not UI speed. Next steps are broader slip coverage, evidence-linked confidence signals, and stronger compliance controls. This is an AI-native redesign of work, not AI layered onto a legacy process.”

## Recording tips

- Keep cursor movement slow and deliberate.
- Pause 0.5–1.0s after each section transition.
- Zoom browser/app text to be readable in a laptop recording.
- If a warning appears, treat it as a resilience feature and continue.
